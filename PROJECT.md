## Kursens perspektiv

Ni behöver inte lösa allt från början. Återvänd till frågorna när de blir relevanta i kursen.

### Klienten

- Vilka delar finns i HTML/DOM?
- Vilka JavaScript-events reagerar på användaren?

### State och lagring

- Behöver browsern komma ihåg något?
- Var lagras det i så fall?

### Identifiering

- Behöver ni skilja på browser, session eller användare?

### Tracking och observation

- Vilka händelser är relevanta att observera?
- Hur kan ni bevisa att de inträffar?

### Nätverk

- Vilka requests skickas?
- Vad innehåller payload och response?

### Consent

- Finns något som bör bero på användarens samtycke?

### Felsökning

När något går fel:

1. Vad förväntade vi oss skulle hända?
2. Vad kan vi faktiskt observera?
3. Vilket är det sista ledet vi vet fungerar?
4. Vilket litet test skiljer möjliga orsaker åt?
5. Vad bevisar att problemet är löst?
